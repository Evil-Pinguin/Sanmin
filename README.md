# Санмин — тест по санитарно-эпидемиологическому благополучию

Небольшой интерактивный сайт-тест на русском языке: 55 вопросов по Закону № 52-ФЗ, производственному контролю, санитарным требованиям к организациям для детей и молодёжи и учебно-тематическому плану.

## Запуск

Проект не требует сборки и зависимостей. Откройте `index.html` в браузере или запустите локальный статический сервер из корня репозитория:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

## Возможности

- случайный порядок вопросов и вариантов ответа при каждом прохождении;
- пояснение после выбора ответа;
- итог в баллах и процентах, статистика и список ошибок;
- адаптивная вёрстка для мобильных устройств.
